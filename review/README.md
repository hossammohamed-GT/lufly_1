# مراجعة صور المطبخ — الحالة الأصلية

هذا المجلد لعرض **الصور الأصلية** لمنتجات المطبخ الـ24 الظاهرة في جريد
`/en/products?category=kitchen`، بعد الرجوع بها إلى حالتها قبل أي إعادة توليد
أو حفر لوجو (نفس حالة الكوميت `82ca5ee`).

- `index.html` — معرض عربي من اليمين لليسار: كل صورة كارت برقمها، وتكبير
  بالأسهم، وزرّي «حجم مناسب / حجم كامل».
- `lufly_kitchen_original_1..4.png` — 4 لوحات جاهزة (3×2 لكل لوحة).
- `lufly_kitchen_original.pdf` — نفس اللوحات الأربع في ملف واحد.
- `img/01.webp … img/24.webp` + `items.json` — نفس الصور مضغوطة للعرض.

الترقيم مطابق لترتيب الموقع، وليس لترتيب قاعدة البيانات.
