## ٣ حاجات في السكيما **مش** زي الـ sqlite الخام — وده مقصود

الداتا نفسها متطابقة 100%، لكن السكيما فيها ٣ فروق لازمة عشان الاستيراد ينفع
(وكلها متأكدة إنها مش بتغيّر أي صف):

1. **`AUTO_INCREMENT` = `max(id)+1`** لكل جدول. في النسخ القديمة كان أقل من أعلى
   `id` (مثال: `media` 1501 وأعلى id 1660) → أول إضافة/رفع صورة على MySQL كان
   هيضرب `Duplicate entry`.
2. **مفيش `CHECK (json_valid(...))`** على أعمدة الـ JSON. الداتا اللوكال فيها 18 صف
   `media.meta` مش JSON صالح (فيهم `\\"` زيادة)، ولو الـ CHECK موجود كان الـ import
   هيفشل عندهم. الكود بيقراهم عادي (`json_decode(...) ?? []`) فمفيش أي فرق في الموقع.
3. **مفيش `COLLATE utf8mb4_bin`** على مستوى العمود — الـ collation ده مش موجود في كل
   نسخ MySQL 8 / MariaDB وكان ممكن يقطع الاستيراد بـ `Unknown collation`.

لو عايز الملف يبقى **sqlite خام حتى في السكيما** (بالـ `json` type والـ `CHECK`)،
قولّي وأعمله — الجزء بتاع الداتا جاهز أصلاً.
